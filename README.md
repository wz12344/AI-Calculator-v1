🔬 Advanced Math Assistant (Научный Калькулятор с AI)Этот проект представляет собой многофункциональный веб-инструмент, объединяющий традиционный научный калькулятор, решатель уравнений и мощные функции искусственного интеллекта (Gemini LLM) для символьного упрощения, решения задач по фотографии и генерации учебного контента.Он полностью реализован в одном HTML-файле, что делает его легким для развертывания и использования.🌟 Ключевые ВозможностиИнтерактивный Научный Калькулятор:Поддерживает базовые операции, тригонометрию (в градусах), корни, степени и константу π.Автоматически преобразует десятичные результаты в обыкновенные дроби (если возможно).Символьное Упрощение и Решение Уравнений (через AI):Используйте переменные X и Y или оранжевую кнопку '=' (EQUAL_DEFINE) для создания уравнений (например, 2*X + 5 = 10).Кнопка '=' (зеленая) отправляет выражение или уравнение AI для символьного упрощения или нахождения корней. Результаты выводятся в LaTeX через MathJax.Решатель Квадратных Уравнений (DISC/KORNI):Отдельный режим для быстрого нахождения дискриминанта и корней уравнения Ax2+Bx+C=0, включая комплексные корни.AI Решатель Задач по Фото (Vision):Загрузите изображение математической задачи (рукописный или печатный текст).AI распознает, решит задачу и предоставит пошаговое решение на русском языке.Генератор Уроков и Задач (Gemini AI):Введите любую математическую тему (например, "Производные", "Интегралы", "Дроби").AI сгенерирует подробное объяснение концепции и ровно 3 практические задачи с решениями для самопроверки.🛠️ ТехнологииHTML/CSS/JavaScript: Основа всего приложения, реализованная в одном файле.Tailwind CSS: Используется для быстрого и адаптивного оформления интерфейса.MathJax 3: Используется для красивого и правильного отображения сложных математических формул в формате LaTeX.Gemini API (LLM): Используется для всех функций AI (символьное решение, распознавание по фото, генерация уроков).🚀 Как ЗапуститьПоскольку это один самодостаточный HTML-файл, запуск предельно прост:Скачайте файл: Сохраните scientific_calculator_with_vision.html на свой компьютер.Откройте в браузере: Дважды кликните по файлу или откройте его в любом современном веб-браузере (Chrome, Firefox и т.д.).Использование AI-функций: Чтобы использовать AI-функции (символьный решатель, фото-решатель, генератор уроков), вам потребуется Gemini API Key. В рабочем окружении (Canvas) ключ предоставляется автоматически.🔑 Важное Примечание об APIДля корректной работы разделов "AI Решатель Задач по Фото" и "Генератор Задач и Объяснений" требуется доступ к Gemini API. В текущей реализации в коде используется переменная apiKey = "", которая автоматически подставляется средой исполнения. Если вы запускаете файл локально, вам необходимо самостоятельно добавить свой ключ.const apiKey = "ВАШ_API_КЛЮЧ_ЗДЕСЬ";
